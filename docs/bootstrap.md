# Bootstrap

The bootstrap is part of the JAOT that gets us from a machine with a C++ compiler to a Java compiler that can build itself.

## Stage 0

Stage 0 is the C++ compiler.

It only needs to understand the first version of the JAOT language and generate working native code.

This implementation should support:
- classes
- methods
- primitive values
- local variables
- arithmetic
- comparisons
- conditionals
- loops
- method calls
- return statements
- simple object allocation

There will be a lot of shortcuts to make progress faster ig ;)
